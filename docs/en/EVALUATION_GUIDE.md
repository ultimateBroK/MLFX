# ML_FX - Evaluation Guide

This guide explains how to run backtests and interpret the reports generated by `eval/run_eval.py` and `viz/charts.py`.

## 1. Input Data

The current evaluation flow reads a labeled parquet file directly, for example:

```text
data/labels/XAUUSD/1H/2024-01.parquet
```

Typical signal columns are:
- `label_5`
- `label_10`
- `label_20`

The backtest flow does not require a separate `predictions.parquet` file. If your input dataset already contains a usable signal column, `eval/run_eval.py` can consume it directly.

## 2. Run a Backtest

```bash
pixi run python eval/run_eval.py \
  --data data/labels/XAUUSD/1H/2024-01.parquet \
  --symbol XAUUSD \
  --tf 1H \
  --label label_10 \
  --tp 1.5 \
  --sl 1.0 \
  --slippage 0.0 \
  --outdir outputs/reports
```

Argument meanings:
- `--data`: input parquet file
- `--symbol`: symbol name for chart titles
- `--tf`: timeframe label for outputs
- `--label`: signal column used during simulation
- `--tp`: take-profit in R units
- `--sl`: stop-loss in R units
- `--slippage`: execution slippage
- `--outdir`: report directory, default `outputs/reports`

## 3. Core Metrics

The terminal output typically includes:
- `Total Trades`
- `Win Rate (%)`
- `Profit Factor`
- `Net Profit (R)`
- `Net Profit ($)`
- `Sharpe Ratio`
- `Sortino Ratio`
- `Calmar Ratio`
- `Final Capital ($)`

Quick interpretation:
- `Profit Factor > 1` means the strategy is profitable on that dataset
- `Max drawdown` and `Final Capital` give more realistic risk information than win rate alone
- `Net Profit (R)` is useful when comparing multiple setups under the same risk framework

## 4. Generated Files

`viz/charts.py` currently writes 3 report files into `outputs/reports`:

- `{prefix}_candlestick.html`
- `{prefix}_equity.png`
- `{prefix}_heatmap.png`

Where `prefix = {label}_R{tp*10}`. Example:

```text
outputs/reports/label_10_R15_candlestick.html
outputs/reports/label_10_R15_equity.png
outputs/reports/label_10_R15_heatmap.png
```

## 5. Reading Each Chart

### 5.1 Candlestick

The HTML candlestick report uses Plotly to display:
- price candles
- LONG/SHORT/NEUTRAL markers
- any indicator panels present in the dataset

Use this file when you want to inspect specific trade signals in context.

### 5.2 Equity Curve

The `*_equity.png` file shows:
- cumulative profit in R
- drawdown underneath

If the equity curve rises but drawdowns are too deep, the setup may still be difficult to operate in practice.

### 5.3 Heatmap

The `*_heatmap.png` file summarizes performance by UTC hour and weekday.

This is useful for questions such as:
- whether the setup performs better during London or New York sessions
- whether certain hours consistently underperform
- whether a session filter would improve results

## 6. Minimal Python Example

```bash
pixi run python -c "
import polars as pl
from eval.backtest import simulate_trades, compute_metrics
from viz.charts import generate_full_report
from pathlib import Path

df = pl.read_parquet('data/labels/XAUUSD/1H/2024-01.parquet')
trades = simulate_trades(df, signal_col='label_10', tp_r=1.5, sl_r=1.0, slippage=0.0)
metrics = compute_metrics(trades)
print(metrics)
generate_full_report('XAUUSD', '1H', df, trades, 'label_10_R15', Path('outputs/reports'))
"
```

## 7. Validation Tips

- compare multiple `label_col` values on the same symbol and timeframe
- do not judge a setup by `Win Rate` alone; always compare `Profit Factor`, `Net Profit (R)`, and drawdown
- if the heatmap shows weak performance outside liquid sessions, test additional session-based filters in your pipeline or strategy logic
